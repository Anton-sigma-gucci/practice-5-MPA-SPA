# Практична робота №5
## Створення односторінкового вебзастосунку (SPA)

### Мета роботи
Закріпити навички роботи з JavaScript, DOM і BOM, навчитися реалізовувати обробку подій та створювати односторінкові вебзастосунки (SPA) із клієнтською маршрутизацією.

### Використані технології
- **HTML5** — структура вебсторінки.
- **CSS3** — оформлення та адаптивний дизайн.
- **JavaScript (Vanilla JS)** — логіка застосунку, робота з DOM, BOM та обробка подій.
- **GitHub Pages** — публікація вебзастосунку.
